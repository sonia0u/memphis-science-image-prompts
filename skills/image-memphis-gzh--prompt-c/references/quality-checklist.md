# 输出质检清单（孟菲斯扁平风）

在最终回答前逐项检查。任何一项失败都先修改，不要把检查过程输出给用户。

## 输入与范围

- [ ] 已读取完整文章，而不是只根据标题或片段生成。
- [ ] 文章足以支持所有上图事实；没有加入外部知识。
- [ ] 输出只包含分镜简表和完整提示词，没有实际生图。

## 张数与分镜

- [ ] 图片总数为 3 至 5 张，或严格遵循用户在该范围内的明确指定。
- [ ] 图 1 是封面，最后一张是收尾，正文图为 1 至 3 张。
- [ ] 每张正文只承担一个主要理解任务。
- [ ] 正文角色来自文章结构，没有机械套用固定“原因 + 机制”。
- [ ] 超过 3 个核心内容单元时，选择的是最重要的 3 个。

## 事实与文案

- [ ] 数字、单位、日期、专有名词和引用与原文一致。
- [ ] 没有把相关关系改成因果关系，没有放大确定性或适用范围。
- [ ] 封面标题不超过 22 字，副标题不超过 24 字。
- [ ] 正文标题不超过 20 字，正文为 45 至 80 字并拆成 2 至 4 段或要点。
- [ ] 收尾标题不超过 20 字，正文不超过 60 字，短句不超过 24 字。
- [ ] 收尾没有引入新事实。

## 视觉一致性

- [ ] 每张都明确写出 `3:4` 竖版。
- [ ] 每张都完整写出长春花蓝、珊瑚红、奶油杏、深藏青、白色五个色值。
- [ ] 每张都指定思源黑体 Bold（标题）和阿里巴巴普惠体 Regular（正文）。
- [ ] 每张都写明扁平矢量插画、孟菲斯装饰元素（十字星、加号、圆点、斜线、速度线、同心圆）、半调波点纹理和大弧形波浪背景分割。
- [ ] 人物统一为齐刘海短发小女孩形象，圆点腮红、条纹上衣、扁平色块画法保持一致。
- [ ] 珊瑚红只作为小面积强调，没有成片使用或改变三色体系。
- [ ] 蓝底上用白色/深藏青文字，奶油底上用深藏青文字，明暗对比清楚。

## 提示词完整性

- [ ] 每张提示词都能脱离其他提示词单独使用。
- [ ] 没有“同上”“延续上一张”“保持之前风格”等上下文依赖表述。
- [ ] 每张都包含画布、视觉锚点、主体、构图、精确文字、字体、位置、光线和正向约束。
- [ ] 所有方括号占位符都已替换或删除。
- [ ] 没有额外输出独立 negative prompt。

## 最终格式

- [ ] 分镜表只有“图片、角色、核心信息”三列。
- [ ] 提示词从 `图 1` 到 `图 N` 连续编号。
- [ ] 每张提示词位于独立的 `text` 代码块中。
- [ ] 代码块外没有冗长分析、额外策划或使用说明。
