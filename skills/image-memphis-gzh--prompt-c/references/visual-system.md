# 固定视觉系统（孟菲斯扁平插画风）

每一张提示词都必须完整写入本文件的视觉要求。不得只在第一张声明，也不得用“同系列”“延续前图”代替具体描述。

## 系列视觉锚点

将以下语义完整融入每张提示词：

> 3:4 竖版，扁平矢量插画风格，孟菲斯（Memphis）装饰语言：画面点缀十字星、加号、小圆点、细斜线、速度线和同心圆几何元素；主体使用半调波点纹理营造复古丝网印刷质感。色彩为高辨识度三色体系：长春花蓝、珊瑚红、奶油杏，辅以深藏青和白色；背景用大弧形波浪色块分割。人物为圆润卡通小女孩形象（齐刘海短发、圆点腮红）。画面活泼、明快、有印刷海报感，文字层级清晰，适合小红书和微信公众号科普图。

## 色彩令牌

| 用途 | 色值与规则 |
| --- | --- |
| 主背景 | 长春花蓝 `#5C6CBD`（蓝色大色块区域） |
| 次背景 / 文字区 | 奶油杏 `#F8DEC0`（波浪弧形色块） |
| 强调与点缀 | 珊瑚红 `#F0563A`（书本、圆点、强调图形，占画面 10%–20%） |
| 深色主体与文字 | 深藏青 `#2E3A87`（插画深色块、蓝底上的标题描边、奶油底上的正文） |
| 提亮 | 纯白 `#FFFFFF`（蓝底上的标题字、白色图形与高光） |

用色规则：

- 蓝底之上用白色或深藏青文字与浅色插画；奶油杏底之上用深藏青文字。
- 珊瑚红只做强调色，不成片使用；每张图珊瑚红占比保持相近，维持系列一致。
- 不要引入蓝红奶油之外的第四种色相，不使用渐变、高饱和霓虹色或写实光影。
- 主体插画（地球、书本、圆形等）使用深藏青大色块加白色半调波点纹理。

## 字体与文字层级

- 主标题、章节标题：思源黑体 Bold（蓝底上用白色并带轻微深藏青描边感，奶油底上用深藏青）。
- 正文、辅助文字、短句：阿里巴巴普惠体 Regular（奶油底或白色文字区上用深藏青）。
- 主标题最大，章节标题次之，正文和辅助文字明显更小。
- 指定准确的文字位置、对齐方式和文字区范围；保持宽松行距和段间距。
- 文字不得遮挡人物、图标、关键动作或视觉隐喻。

## 人物设定

- 系列所有人物统一为**同一小女孩形象**：圆润卡通造型，齐刘海短发，红晕圆点腮红，表情安静友好。
- 服装为横条纹上衣与深色下装的组合，配色限于珊瑚红、白色、深藏青。
- 所有人物保持相同年龄感、发型轮廓、服装色系和扁平色块画法；只改变姿态、朝向和手部动作。
- 单张图内出现多个人物时，均为同一套设定，不改变形象语言。
- 人物不使用写实五官、渐变上色或描边勾线以外的复杂细节。

## 构图与组件

- 背景由 1 至 2 个大弧形波浪色块分割（如蓝色在上、奶油杏在下，或左右分割），边缘是平滑的大圆弧，不是直线。
- 孟菲斯装饰元素（十字星、加号、小圆点、斜线、速度线、同心圆）散布在留白区域，密度适中，每张保持相近的元素密度与分布节奏。
- 文字区落在奶油杏色块或白色圆角底上，圆角克制，不使用厚重投影。
- 图标保持同一粗细和简化程度，扁平色块画法。
- 插画主体（地球、书本、植物、器物等）用深藏青色块 + 白色波点 + 珊瑚红点缀的组合语言，保持系列统一。
- 光线为均匀平面光，无光源方向、无投影渐变，靠色块明度区分层次。

## 可变范围

只允许按单图信息改变：

- 人物姿态、朝向和互动对象。
- 视觉隐喻，例如书本、路径、对照分区、时间节点、波纹或阶梯。
- 波浪分割的方向（上/下/左/右/斜向）与蓝、奶油两色的面积比例。
- 文字区位于左、右、上或下的位置。
- 孟菲斯元素的种类组合（在锚点列举的元素内挑选），不新增元素种类。

不要改变画幅、三色体系、字体角色、扁平画法、波点纹理、波浪背景语言、人物基本设定或装饰元素体系。

## 正向约束写法

把限制写成期望结果：

- 写“背景为干净的扁平色块，仅有波点与几何装饰”，不要依赖“不要复杂背景”。
- 写“画面只保留一个主视觉焦点”，不要依赖“不要杂乱”。
- 写“文字区完整、无遮挡、边缘留有安全距离”，不要依赖“文字别被裁切”。
- 写“仅使用长春花蓝、珊瑚红、奶油杏、深藏青和白色”，不要只列出禁止颜色。
