# 孟菲斯风科普图提示词生成 Skill

把一篇完整文章转化为 **3–5 张风格统一的 3:4 竖版科普图提示词**，视觉体系为**孟菲斯扁平插画风**（长春花蓝 + 珊瑚红 + 奶油杏撞色、半调波点、几何装饰元素）。提示词可直接喂给 AI 绘图工具（本地画布 / Midjourney / SD 等）出图，适用于小红书、微信公众号的系列科普配图。

> 本 Skill 只生成「分镜表 + 生图提示词」，不调用任何图像生成工具、不发布内容。

## 风格一览

| 维度 | 设定 |
| --- | --- |
| 配色 | 长春花蓝 `#5C6CBD`（主背景）、奶油杏 `#F8DEC0`（文字区）、珊瑚红 `#F0563A`（小面积强调）、深藏青 `#2E3A87`、白，锁定五色、禁第四色相 |
| 装饰 | 孟菲斯元素（十字星、加号、圆点、斜线、速度线、同心圆）+ 白色半调波点纹理 + 大弧形波浪背景分割 |
| 人物 | 圆润卡通小女孩（齐刘海短发、圆点腮红、条纹上衣） |
| 字体 | 思源黑体 Bold（标题）+ 阿里巴巴普惠体 Regular（正文） |

## 安装 / 使用

1. 将整个 `image-memphis-gzh--prompt-c` 文件夹放入 WorkBuddy 的 `skills/` 目录（用户级或项目级）。
2. 对 AI 说：「帮我把这篇文章做成孟菲斯风科普图提示词」，并贴入完整文章（或给出本地 md 路径）。
3. Skill 会输出分镜表 + 每张图的独立提示词，复制提示词到绘图工具即可。

也可在对话中直接触发关键词：孟菲斯科普图、扁平插画科普图、撞色科普图、memphis 科普图。

## 示例

`examples/` 内 5 张图来自文章《精神内耗的尽头，是行动》，演示同一套风格的封面 + 正文 + 收尾一致性：

- 图 1 封面：深夜枕头上脑中「讨论会」气泡
- 图 2 机制：大脑空转＝死踩油门的车
- 图 3 真相：做了才想清楚（简历→灯泡路径）
- 图 4 方法：五分钟法则，先换鞋
- 图 5 收尾：先把鞋穿上，剩下的走着瞧
