# 分镜与文案规则

## 判断核心内容单元

一个核心内容单元必须同时满足：

1. 对理解文章主旨不可缺少。
2. 可以用一张图表达一个主要问题或结论。
3. 与其他单元不是同义重复或单纯例证。
4. 有明确的视觉对象、关系、动作或隐喻。

先合并重复段落，再按“主旨支撑度、读者理解价值、可视化清晰度”排序。

## 图片数量

| 核心内容单元 | 图片数量 | 结构 |
| --- | --- | --- |
| 1 个 | 3 张 | 封面 + 1 张正文 + 收尾 |
| 2 个 | 4 张 | 封面 + 2 张正文 + 收尾 |
| 3 个及以上 | 5 张 | 封面 + 最重要的 3 张正文 + 收尾 |

用户明确指定 3 至 5 张时，以指定数量为准。用户指定范围外数量时，说明本 Skill 面向 3 至 5 张系列图，并请用户改选，不要静默截断。

## 正文角色选择

按文章真实结构组合，不要机械套用固定角色：

| 内容信号 | 可选正文角色 |
| --- | --- |
| 解释概念 | 定义、特征、为什么重要 |
| 因果科普 | 现象、原因、机制、影响 |
| 误区澄清 | 常见误区、事实、正确理解 |
| 操作方法 | 前提、步骤、注意事项、结果 |
| 对比内容 | A、B、关键差异、适用条件 |
| 历史演变 | 起点、转折、结果或当代影响 |
| 情绪心理 | 感受、内在机制、边界或行动建议 |
| 案例解释 | 情境、关键变化、结论或启示 |

封面负责提出主旨和吸引阅读，收尾负责总结、边界提醒或温和行动建议。收尾不要引入新事实。

## 文案长度

### 封面

- 主标题：不超过 22 个汉字。
- 副标题：可选，不超过 24 个汉字。
- 优先保留文章标题的核心命题；过长时压缩，不制造夸张承诺。

### 正文

- 章节标题：不超过 20 个汉字。
- 正文总量：45 至 80 个汉字。
- 拆成 2 至 4 个短段、短句或要点，每段只表达一件事。
- 用文章的准确术语，不为了简短而改变专业含义。

### 收尾

- 标题：不超过 20 个汉字。
- 正文：不超过 60 个汉字。
- 共勉或总结短句：可选，不超过 24 个汉字。

## 压缩规则

1. 先删除重复修饰、铺垫和不影响结论的例子。
2. 再合并相邻同义句，保留核心主谓宾。
3. 保持数字、单位、日期、专有名词、引用归属、条件范围和概率表达原样。
4. 保持“相关”与“因果”、“可能”与“必然”、“部分”与“全部”的区别。
5. 内容仍过长时增加正文图，最多增加到 3 张；已经达到 5 张时，保留最重要的 3 个正文单元。

## 分镜表

最终只输出以下三列：

| 图片 | 角色 | 核心信息 |
| --- | --- | --- |
| 图 1 | 封面 | 一句话说明主旨 |
| 图 2 | 与文章匹配的角色 | 一句话说明本图任务 |
| ... | ... | ... |
| 图 N | 收尾 | 一句话说明总结或行动建议 |

不要在表中展开视觉规范、全文文案或分析理由。
