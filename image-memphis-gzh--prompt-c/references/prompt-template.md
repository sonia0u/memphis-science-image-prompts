# 独立提示词模板（孟菲斯扁平风）

每张提示词按以下顺序组织，并把所有占位内容替换为本篇文章的实际内容。不要保留方括号占位符。

## 固定顺序

1. 画布与固定视觉锚点。
2. 本图角色和信息目的。
3. 画面主体、动作与视觉隐喻。
4. 构图分区、波浪背景和文字区。
5. 精确上图文字、字体、大小关系、对齐和位置。
6. 光线、细节、清晰度和正向约束。

## 通用模板

## 封面补充

- 标题是第一视觉焦点，位于蓝色区，使用白色大字；人物或象征性主体位于标题之外的稳定区域。
- 副标题只用于补充主旨，不重复标题。
- 封面不放长正文，装饰元素可略多于正文图但仍保持克制。

## 正文补充

- 一张图只解释一个核心内容单元。
- 机制使用路径、波点连线、层级或因果连接表达；步骤使用清晰顺序；对比使用稳定左右分区；时间线使用单向阅读路径。
- 正文拆成 2 至 4 个短段或要点，写在奶油杏文字区内，并在提示词中写明换行或分段关系。
- 插画和文字必须形成互补，不用装饰性人物重复正文表面含义。

## 收尾补充

- 使用更开阔的奶油杏区域和更明亮的留白，可增加少量珊瑚红正向强调（如上升箭头、展开的书本），保持三色体系不变。
- 画面表达总结、边界或温和行动，不增加新事实。
- 共勉短句位于底部或独立留白区，不与正文争夺层级。
