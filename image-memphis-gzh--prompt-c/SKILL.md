# 生成系列科普图提示词（孟菲斯扁平风）

把一篇完整文章转化为 3 至 5 张风格统一的中文科普图提示词。始终采用固定的孟菲斯扁平插画视觉体系（靛蓝 + 珊瑚红 + 奶油杏撞色、半调波点、几何装饰元素），同时让正文图角色随文章结构变化。

## 输入要求

1. 接受用户粘贴的完整文章或可读取的本地文章文件。
2. 先阅读全文，再开始拆解。不要只根据标题或开头推断全文。
3. 如果输入只有标题、主题、提纲或零散观点，要求用户补充完整文章并停止生成提示词。
4. 默认使用简体中文，生成一套同时适用于小红书和公众号的通用版本。
5. 只使用文章中已有的事实。不要联网补充知识，不要增加文章未支持的因果关系、数字或结论。

## 工作流

### 1. 建立内容地图

在内部提取主旨、必要的核心内容单元、关键数字、单位、专有名词、引用和适合可视化的对象。不要向用户输出冗长分析。

将“核心内容单元”定义为：对理解文章主旨不可缺少、可以由一张图独立解释、且不是重复例证的观点。阅读 [storyboard-rules.md](references/storyboard-rules.md) 完成分类、排序和文案压缩。

### 2. 决定图片数量

- 用户明确指定 3 至 5 张时，使用指定数量。
- 用户未指定时：1 个核心内容单元生成 3 张；2 个生成 4 张；3 个及以上生成 5 张。
- 始终包含 1 张封面和 1 张收尾；正文图为 1 至 3 张。
- 超过 3 个核心内容单元时，只选对主旨最重要的 3 个，不把多个独立观点塞入同一张图。

### 3. 设计分镜与上图文案

根据文章选择定义、原因、机制、步骤、对比、误区、案例、时间线或建议等正文角色。不要固定套用“原因 + 机制”。

为每张图确定一个主要理解任务、一个明确视觉主体和精确上图文字。压缩文案时保持数字、单位、专有名词、条件、因果关系和不确定性不变。

### 4. 构建独立提示词

阅读 [visual-system.md](references/visual-system.md)，逐字落实固定配色、字体和系列视觉锚点。阅读 [prompt-template.md](references/prompt-template.md)，按规定顺序写每张完整提示词。

每张提示词必须自包含。完整重复画布、配色、字体、纹理、装饰元素、卡片、人物和光线规则；不要使用“延续上一张”“同上”等依赖上下文的表述。

只使用正向语义约束，例如“背景干净、文字区无遮挡”。不要额外输出独立 negative prompt。

### 5. 质检并输出

使用 [quality-checklist.md](references/quality-checklist.md) 检查张数、事实、字数、系列一致性和提示词独立性。任何一项不合格都先修正再输出。

最终回答只能包含：

1. 一张简短分镜表，列为“图片、角色、核心信息”。
2. 按 `图 1` 至 `图 N` 排列的完整提示词；每张放在独立的 `text` 代码块中。

不要输出内容分析过程、额外策划说明、实际图片、图片文件或单独负面提示词。

## 边界

- 不调用任何图像生成工具。
- 不替用户发布到小红书或公众号。
- 不做文章事实核验或外部研究；发现文章内部矛盾或关键信息缺失时，先指出问题并请求用户确认。
- 不因文章题材改变既定视觉体系；只改变画面主体、动作、视觉隐喻和少量情绪强调色。
